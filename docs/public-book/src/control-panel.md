# Updater Control Panel

The loopback Control Panel exposes the fleet dashboard and extended operations
without replacing the CLI or TUI.

## Supported operations

- Fleet task discovery and diagnostics
- Non-mutating plan generation
- Apply, repair/retry, service restart, and rollback actions
- Visible action results and duplicate-action protection
- Theme and repository workspace status

The Panel is intended for local use. Keep it bound to loopback and place any
remote access behind an authenticated, explicitly configured gateway.
