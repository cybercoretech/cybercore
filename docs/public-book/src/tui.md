# Updater TUI

The TUI is a Ratatui dashboard for selecting fleet tasks and reviewing real
operation state.

| Key | Action |
|---|---|
| `I` | Inspect fleet diagnostics |
| `T` | Inspect theme health |
| `U` | Confirm theme synchronization |
| `G` | Read GitHub repository status |
| `D` | Review repository differences |
| `H` | View operation history |
| `P` | Preview a plan |
| `Enter` | Confirm and apply |
| `R` | Confirm repair/retry |
| `S` | Confirm service restart |
| `B` | Confirm rollback |
| `Y` / `N` | Confirm or cancel |
| `Q` / `Esc` | Quit or cancel |

Cybercore status colors distinguish navigation, selection, ready, running,
failure, and diagnostics states.
