# CyberDark Wallpapers

Twelve original, static SVG wallpapers for Cybercore desktops and site previews. The collection follows the Blackbox direction of near-black industrial hardware, exposed racks, server rooms, blueprint marks, cable runs, hazard geometry, and restrained cyan, magenta, violet, blue, and orange light.

Each wallpaper is a 3840x2160 SVG with accessible title/description metadata, no external dependencies, and a low-performance profile. The artwork is intentionally original and does not copy Blackbox branding or source assets.

Use `manifest.json` as the governed contract. Checksums cover every wallpaper.
