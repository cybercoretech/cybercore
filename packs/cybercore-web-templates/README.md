# ✨ Cybercore Web Templates

Source for the `cybercore.web-templates` pack. Each template is a single,
dependency-free HTML page wired to the live Cybercore kit, so it picks up new
themes, components and chooser fixes without edits.

- `tool-landing.html`: a project landing page with the theme chooser in the
  navbar, hero, feature grid, install block and footer. Mobile first.
