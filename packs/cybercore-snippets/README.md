# ✨ Cybercore Snippets

Source for the `cybercore.snippets` pack: reviewed, copy-ready examples for
web pages, Rust tools and CI. List every file in `snippets.json`; the export
(`tools/export-distribution.py packs`) fails when the index and the files
disagree. The Rust snippets are compile-checked against the crate before a
change is merged (see `docs/distribution.md`).
