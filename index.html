    01 / THE MODEL

    Understand the
    layers.

    Cybercore keeps the shared contract separate from the tools that consume it. Start at the source, then choose the distribution path that fits your project.

    01

    Schema

    Palette, theme metadata, tokens, and canonical paths in readable JSON.

    schema/cybergrid.json
    02

    Crates

    Typed Rust contracts for loading, validating, composing, and publishing resources.

    cargo add cybercore-core
    03

    Packs

    Versioned resources with manifests, provenance, compatibility, and checksums.

    cybercore-control pack install
    04

    Consumers

    Apps and sites read the same source without copying or redefining the system.

    From zero to
    shared surface.

    Use the core crate in a Rust project, install a governed pack into the current workspace, or read the canonical schema from another runtime.

    cargo add cybercore-core

let themes = ThemeCatalog::load()?;
